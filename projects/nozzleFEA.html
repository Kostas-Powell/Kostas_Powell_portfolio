Nozzle FEA

Structural finite element analysis of a hybrid rocket nozzle retention system using ANSYS Mechanical.

Overview

What this project is about.

This summer I've been tasked with investigating the transition from using Solidworks to Ansys Mechnaical to conduct the Queen's Rocket Engineering Team's finite element analysis. I decided the best way to do this would be to conduct stress testing of a component of the rocket. I decided to evaluate whether the nozzle assembly could safely withstand thrust loads, chamber pressure, and mechanical retention forces during engine operation.

The purpose of this project is not only to verify the strength of the nozzle assembly, but also to develop a repeatable FEA workflow that the team can use for future rocket components. This includes learning how to import and simplify CAD geometry, define realistic material properties and contacts, apply appropriate boundary conditions, create a reliable mesh, and interpret stress, deformation, and factor of safety results.

By using the nozzle as a test case, I can compare ANSYS Mechanical's capabilities against the team's previous SolidWorks Simulation workflow and identify where ANSYS provides better control over meshing, contacts, loading, and result interpretation. The final goal is to create both a validated analysis of the nozzle retention system and a clearer process for future structural analysis work within QRET.
