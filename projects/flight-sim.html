Jet Engine Simulator

MATLAB and Python simulation project modeling turbojet and turbofan engine performance, atmospheric effects, and aircraft flight dynamics.

Overview

What this project was about.

This was a short self directed summer project I worked on in order to teach myself MATLAB and numerical methods. I knew I would be covering both these topics the following year in University, so I wanted to get a head start on learning them. I decided to program an aircraft engine simulation, so I could study the effects of altitude, speed, bypass ratios, and nozzle sizing on turbofan engines (and turbojets minus the bypass ratio). I compiled this simulation into a MATLAB app, so I could easily adjust parameters and view graphical results.

In order to create this simulation I learned how to preform numerical differentiation and integration within Python, as well as solve differential equations with the RK4 method. My simulation also involved implimenting an environmental model that varried air density and temperatures as a function of altitude. I also learned the working concepts of turbofan and turbojet engines, and how I could preform air-standard modeling of these systems.

Finally I ported this sumulation to Python in hopes to create an interactive aircraft flight simulator. I learned about the different control systems of an aircraft and how they affected the pitch, roll, and yaw. I implimented dynamical models for aircraft's lift and drag as a function of angle of attack. I used my newfound knowledge in linear algebra, which I had taken the previous sememster, to program the global and local positions, rotations, forces, and velocities in terms of matricies, and transform between different coordinate systems. I even learned how to use Quaternions to overcome issues with gimbal lock I faced when testing my simulation. While all the mathematical models are in place for this program, it remains incomplete as I had no interest in learning how to program 3D graphics inside Python.
